# Gifler v0.2.0

## What's new

- Compact dark window controls with improved spacing, resizing, and DPI handling.
- Grab any inner edge or corner to resize, with directional cursors and subtle hover marks. The center remains click-through.
- Capture aspect-ratio locks: 16:9, 9:16, 1:1, 4:5, 4:3, and 3:4, plus Free.
- System-audio recording for MP4 and WebM, including a fix for crackling caused by packet timestamp jitter.
- More frame-rate presets and custom capture rates from 1 to 240 FPS.
- MP4 Social / X preset: 30 FPS H.264, AAC-LC stereo, square pixels, conservative dimensions, and padding for extreme aspect ratios.
- Optional 44.1 kHz MP4 audio export; 48 kHz remains the default. Audio resampling happens during export, not capture.
- Export size targets, progress, cancellation, and improved failure reporting.

## Download and run

Download **Gifler.exe** below. This is a portable, unsigned Windows executable with no installer or .NET requirement. FFmpeg is required for media export and is not bundled; put `ffmpeg.exe` on PATH or at `encoders/ffmpeg.exe` beside Gifler.

Use **More > Capture aspect ratio** to select a locked shape. The format dropdown contains **MP4 Social / X** and **MP4 audio rate**.

## Notes

- The Social / X preset supports clips up to 140 seconds. Regular MP4 remains available for longer recordings and high/custom frame rates.
- X upload acceptance has not been tested against a user account. WebM and animated WebP remain available for destinations that support them.
- Capture FPS is a target, not a guarantee; achieved performance depends on the display, capture area, and hardware.
- Preview playback is visual only. Listen to audio in the exported MP4/WebM.
- Debug/release unit tests, native UI checks, and encoder smoke checks were run locally. Long-running A/V synchronization and additional physical audio devices remain manual test coverage.
